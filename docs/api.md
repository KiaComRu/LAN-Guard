# API v1

Документ OpenAPI доступен администратору по `/openapi/v1.json`. Проверка запуска сервера доступна по `/healthz`.

| Маршрут | Действие |
| --- | --- |
| `GET /api/v1/auth/csrf` | Получить cookie и токен для заголовка `X-CSRF-Token` |
| `POST /api/v1/auth/login` | Вход по JSON с `login` и `password` |
| `POST /api/v1/auth/logout` | Завершить cookie-сессию |
| `GET /api/v1/auth/session` | Получить логин, роль и режим работы |
| `GET /api/v1/overview` | Счётчики панели |
| `GET /api/v1/devices` | Компьютеры, параметры `q`, `status`, `page` |
| `GET /api/v1/devices/{id}` | Карточка ПК, доказательства, покрытие и события |
| `GET /api/v1/detections` | Обнаружения, параметры `family`, `page` |
| `GET /api/v1/events` | Последние 100 событий |
| `GET /api/v1/reports/detections.csv` | CSV обнаружений |
| `GET /api/v1/signatures` | Текущий каталог, только для администратора |
| `POST /api/v1/enrollment-tokens` | Создать одноразовый токен на 30 минут, только для администратора |
| `POST /api/v1/agents/enroll` | Зарегистрировать агента |
| `POST /api/v1/agents/heartbeat` | Обновить метаданные и отметку связи |
| `POST /api/v1/agents/inventory` | Принять отчёт и рассчитать обнаружения |
| `POST /api/v1/agents/rotate` | Заменить секрет устройства |

Агентские запросы после регистрации используют `Authorization: Bearer <agent-id>.<secret>`. При повторной отправке отчёта с тем же `scanId` сервер возвращает успешный ответ без повторного применения. Опоздавший отчёт не заменяет результаты более свежей проверки. Сервер формирует события о первом появлении, запуске, повторном появлении, пропаже из наблюдений и частичной проверке.

Отчёт без совпадений даёт `not_detected` только при актуальной связи с агентом и полном покрытии поддерживаемых источников. Частичный отчёт сохраняет предыдущие обнаружения, которые могли остаться в недоступном источнике. Активность отражает наблюдение процессов на момент проверки. Если от агента три минуты нет heartbeat, панель показывает «Нет связи», а активность становится неизвестной.
