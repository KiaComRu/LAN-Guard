# Архитектура

`LanGuard.Agent` читает локальные источники Windows через `IEndpointInventoryProvider`. Агент пишет отчёт в файловую очередь, затем отправляет его по HTTPS. Успешный ответ сервера позволяет удалить файл. При ошибке связи очередь сохраняется, агент повторяет запросы с задержкой. Состояние регистрации и ротации записывается до сетевого запроса, чтобы восстановиться после прерывания.

`LanGuard.Server` сверяет машинную идентичность и передаёт наблюдения детектору из `LanGuard.Shared`. Сервер обновляет обнаружения, события и квитанцию отчёта в одной операции записи. Ревизия записи устройства обнаруживает конкурирующие изменения. SQLite используется для локального развёртывания, PostgreSQL подключается через дополнительный файл Compose.

`LanGuard.Web` и API обслуживаются с одного HTTPS-адреса. Интерфейс получает текущие наблюдения, время проверки и статус агента через API. Демо использует отдельную БД и блокирует приём данных от агентов.
