# Модель угроз

Данные инвентаризации раскрывают имена устройств, IP, сведения об установленном ПО и пути к исполняемым файлам. Доступ к панели требует учётной записи, выдача токенов требует роли администратора. Сессию защищают HTTPS, HttpOnly cookie и CSRF-токен. Сервер хранит хеши паролей, токенов и секретов устройств.

Скомпрометированный агент может искажать сведения о собственном устройстве. Машинный секрет ограничивает запросы одной записью и не даёт доступа к административной панели. Администратор с системными правами на Windows может изменить работу агента и данные до отправки. Совпадения по реестру и PE-метаданным служат наблюдениями для проверки, а подлинность бинарника требует отдельной криптографической проверки.

Агент использует LocalSystem, поэтому каталоги программы и данных закрыты ACL для SYSTEM и локальных администраторов. Агент читает только метаданные. Для извлечения PE-метаданных он ограничивается фиксированными локальными дисками и пропускает пути с точками повторной обработки. Служба устанавливается администратором на каждом управляемом ПК.

Развёртывание рассчитано на один экземпляр API в доверенной сети с управляемым УЦ. Администратор защищает тома БД, файлы сертификатов и ключи сессий средствами хоста. [Развёртывание](deployment.md)
